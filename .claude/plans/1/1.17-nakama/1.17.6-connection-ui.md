# Nakama Connection Status UI

## Overview
Add connection indicator and quit-interception to handle disconnection gracefully.

**Parent Plan**: [../1.17-nakama-server.md](../1.17-nakama-server.md) (index)
**Depends On**: [1.17.3-cloud-storage.md](1.17.3-cloud-storage.md)

## Purpose
- Visual indicator of connection state in settings panel
- Green dot when connected, orange when disconnected
- Intercept game close when disconnected to warn player
- Prevent data loss by warning user before quitting without saving

---

## Design Philosophy

**Cloud-Only, No Confusion, No Data Loss**

1. **Single source of truth**: Only cloud saves exist. No local fallback.
2. **Player warned before data loss**: Can't accidentally close game while disconnected.
3. **Simple mental model**: "Green = saved. Orange = unsaved progress at risk."
4. **Offline earnings**: Handled by [2.19.8-dishwash-offline.md](../../2/2.19-dishwash/2.19.8-dishwash-offline.md) (out of scope for this plan)

### 6.1 Connection Indicator in Settings Panel

**Add to settings_panel.tscn UI**:
```
SettingsPanel
+-- MarginContainer
    +-- VBoxContainer
        +-- HeaderHBox
        |   +-- TitleLabel ("Settings")
        |   +-- Spacer (Control with expand)
        |   +-- ConnectionStatus (HBoxContainer)
        |   |   +-- ConnectionDot (ColorRect, 12x12)
        |   |   +-- ConnectionLabel ("Connected")
        |   |   +-- RetryButton ("Retry", visible only when disconnected)
        |   +-- CloseButton ("X")
        +-- LastSaveLabel ("Last saved: X minutes ago")
        ...
```

**Add to settings_panel.gd**:
```gdscript
@onready var connection_dot = $MarginContainer/VBoxContainer/HeaderHBox/ConnectionStatus/ConnectionDot
@onready var connection_label = $MarginContainer/VBoxContainer/HeaderHBox/ConnectionStatus/ConnectionLabel
@onready var retry_button = $MarginContainer/VBoxContainer/HeaderHBox/ConnectionStatus/RetryButton
@onready var last_save_label = $MarginContainer/VBoxContainer/LastSaveLabel

func _ready():
	# Existing code...

	# Connect to Nakama signals (event-driven, no polling timer needed)
	NakamaManager.connection_lost.connect(_update_connection_display)
	NakamaManager.connection_restored.connect(_update_connection_display)

	# Connect retry button
	retry_button.pressed.connect(_on_retry_pressed)

	# Update initial status
	_update_connection_display()

func _process(_delta):
	# Update "Last saved: X minutes ago" display
	_update_last_save_display()

func _update_connection_display():
	if NakamaManager.is_connected:
		connection_dot.color = Color(0.2, 0.8, 0.3)  # Green
		connection_label.text = "Connected"
		retry_button.visible = false
	else:
		connection_dot.color = Color(1.0, 0.5, 0.0)  # Orange
		connection_label.text = "Disconnected"
		retry_button.visible = true

func _update_last_save_display():
	if NakamaManager.last_successful_save_timestamp > 0:
		var elapsed = Time.get_unix_time_from_system() - NakamaManager.last_successful_save_timestamp
		var minutes = int(elapsed / 60)

		if minutes == 0:
			last_save_label.text = "Last saved: just now"
		elif minutes == 1:
			last_save_label.text = "Last saved: 1 minute ago"
		else:
			last_save_label.text = "Last saved: %d minutes ago" % minutes
	else:
		last_save_label.text = "Last saved: never"

func _on_retry_pressed():
	retry_button.text = "Retrying..."
	retry_button.disabled = true

	# Attempt save to test connection
	var success = await NakamaManager.save_game()

	retry_button.text = "Retry"
	retry_button.disabled = false

	if success:
		Global.show_notification("Connection restored", Global.NOTIFICATION_TYPE_SUCCESS)
	else:
		Global.show_notification("Still disconnected", Global.NOTIFICATION_TYPE_ERROR)
```

### 6.2 Quit Interception When Disconnected

**IMPORTANT**: `NOTIFICATION_WM_CLOSE_REQUEST` must be handled in the main/root scene, NOT in an autoload. Autoloads may not receive the notification reliably.

**In main scene script (e.g., main.gd, root.gd, or level scene)**:

```gdscript
func _ready():
	# Disable automatic quit - we'll handle it manually
	get_tree().set_auto_accept_quit(false)

	# ... rest of _ready code

func _notification(what):
	if what == NOTIFICATION_WM_CLOSE_REQUEST:
		_handle_quit_request()

func _handle_quit_request():
	if NakamaManager.is_connected:
		# Connected - safe to quit
		get_tree().quit()
	else:
		# Disconnected - show warning popup
		NakamaManager.show_unsaved_progress_warning()
```

**Add to NakamaManager (nakama_client.gd)**:

```gdscript
# Tracks last successful cloud save timestamp (in memory)
var last_successful_save_timestamp: float = 0.0

# Flag to prevent quit during save operation
var _saving_before_quit: bool = false

func show_unsaved_progress_warning():
	"""Public API called by main scene when quit requested while disconnected"""
	_show_unsaved_progress_warning()

func _show_unsaved_progress_warning():
	# Format timestamp for display
	var last_save_str = _format_timestamp(last_successful_save_timestamp)

	# Create popup (uses popup system from popup-system.md)
	var popup = preload("res://ui/popups/unsaved_warning_popup.tscn").instantiate()
	popup.set_last_save_time(last_save_str)
	popup.reconnect_pressed.connect(_on_reconnect_pressed.bind(popup))
	popup.close_anyway_pressed.connect(_on_close_anyway_pressed.bind(popup))

	# Add to PopupContainer
	var popup_container = get_tree().current_scene.get_node_or_null("PopupContainer")
	if popup_container:
		popup_container.add_child(popup)
	else:
		# Fallback if no PopupContainer
		get_tree().current_scene.add_child(popup)

func _format_timestamp(unix_time: float) -> String:
	if unix_time == 0.0:
		return "Never"
	var datetime = Time.get_datetime_dict_from_unix_time(int(unix_time))
	return "%02d:%02d %s" % [
		datetime.hour % 12 if datetime.hour % 12 != 0 else 12,
		datetime.minute,
		"AM" if datetime.hour < 12 else "PM"
	]

func _on_reconnect_pressed(popup: Node):
	# Prevent multiple simultaneous save attempts
	if _saving_before_quit:
		return

	_saving_before_quit = true

	# Update button state
	var reconnect_button = popup.get_node("MarginContainer/VBoxContainer/ButtonHBox/ReconnectButton")
	if reconnect_button:
		reconnect_button.disabled = true
		reconnect_button.text = "Saving..."

	# Attempt to save
	var success = await save_game()

	_saving_before_quit = false

	if success:
		# Save succeeded - close popup and quit
		popup.queue_free()
		await get_tree().process_frame  # Let popup cleanup
		get_tree().quit()
	else:
		# Save failed - re-enable button
		if reconnect_button:
			reconnect_button.disabled = false
			reconnect_button.text = "Reconnect"

		Global.show_notification("Save failed. Still disconnected.", Global.NOTIFICATION_TYPE_ERROR)

func _on_close_anyway_pressed(popup: Node):
	# User chose to quit without saving - close popup and exit
	popup.queue_free()
	await get_tree().process_frame  # Let popup cleanup
	get_tree().quit()
```

**unsaved_warning_popup.gd**:
```gdscript
extends PanelContainer

signal reconnect_pressed
signal close_anyway_pressed

@onready var message_label = $MarginContainer/VBoxContainer/MessageLabel
@onready var reconnect_button = $MarginContainer/VBoxContainer/ButtonHBox/ReconnectButton
@onready var close_anyway_button = $MarginContainer/VBoxContainer/ButtonHBox/CloseAnywayButton

func _ready():
	reconnect_button.pressed.connect(func(): reconnect_pressed.emit())
	close_anyway_button.pressed.connect(func(): close_anyway_pressed.emit())

func set_last_save_time(time_str: String):
	message_label.text = "Last save: %s\nProgress since then will be lost." % time_str
```

## Offline Earnings Calculation

**Out of Scope**: This plan focuses on connection UI and quit interception only.

**Offline earnings are handled by**: [2.19.8-dishwash-offline.md](../../2/2.19-dishwash/2.19.8-dishwash-offline.md)

**Integration Point**: The `timestamp` field in cloud saves is used by the offline earnings system to calculate time elapsed since last successful save.

**Flow**:
1. Player closes game while connected -> save succeeds -> `timestamp` in cloud = close time
2. Player closes game while disconnected -> warned -> cloud save unchanged
3. Player returns -> load cloud save -> offline earnings calculated using `save.timestamp`

**Exploit Prevention**:
- Staying offline longer doesn't help (earnings calculated from last SUCCESSFUL save)
- Disconnecting intentionally doesn't help (same reason)
- Only way to maximize earnings is to stay connected (intended behavior)

## Notes

**Decision: Quit Interception in Main Scene, Not Autoload**
- **Rationale**: `NOTIFICATION_WM_CLOSE_REQUEST` is node-specific, autoloads may not receive it reliably
- **Implementation**: Main scene calls `get_tree().set_auto_accept_quit(false)` and handles notification
- **Benefit**: Guaranteed to catch quit request before it processes

**Decision: Event-Driven Updates, No Polling**
- **Rationale**: Signals (connection_lost, connection_restored) already provide events
- **Implementation**: Remove periodic timer, update only on signal emission
- **Benefit**: More efficient, no unnecessary updates

**Decision: Race Condition Prevention**
- **Rationale**: User could close window during reconnect save operation
- **Implementation**: `_saving_before_quit` flag, disable button during save
- **Benefit**: Prevents duplicate saves and inconsistent state

**Decision: Popup Cleanup Before Quit**
- **Rationale**: Popup should close cleanly before quit (no visual glitch)
- **Implementation**: `popup.queue_free()` + `await get_tree().process_frame` before `get_tree().quit()`
- **Benefit**: Professional, polished UX

**Decision: Delegate Offline Earnings to Dishwash Plan**
- **Rationale**: Offline earnings formula is game-specific, not infrastructure
- **Scope**: This plan provides `timestamp` infrastructure, dishwash plan implements earnings
- **Cross-reference**: [2.19.8-dishwash-offline.md](../../2/2.19-dishwash/2.19.8-dishwash-offline.md)
