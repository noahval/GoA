# Nakama Connection Status UI

## Overview
Add connection indicator and quit-interception to handle disconnection gracefully.

**Parent Plan**: [../1.17-nakama-server.md](../1.17-nakama-server.md) (index)
**Depends On**: [1.17.3-cloud-storage.md](1.17.3-cloud-storage.md)

## Purpose
- Visual indicator of connection state in settings panel
- Green dot when connected, orange when disconnected
- Intercept game close when disconnected to warn player
- Prevent offline time exploitation (earnings calculated from last successful save only)

---

## Design Philosophy

**Cloud-Only, No Exploits, No Confusion**

1. **Single source of truth**: Only cloud saves exist. No local fallback.
2. **Offline earnings**: Always calculated from `last_successful_save` timestamp in cloud.
3. **Player warned before data loss**: Can't accidentally close game while disconnected.
4. **Simple mental model**: "Green = saved. Orange = unsaved progress at risk."

**Add to settings_panel.gd**:
```gdscript
@onready var connection_dot = $MarginContainer/VBoxContainer/HeaderHBox/ConnectionStatus/ConnectionDot
@onready var connection_label = $MarginContainer/VBoxContainer/HeaderHBox/ConnectionStatus/ConnectionLabel

func _ready():
	# Existing code...

	# Connect to Nakama signals
	NakamaManager.connection_lost.connect(_on_connection_lost)
	NakamaManager.connection_restored.connect(_on_connection_restored)

	# Update initial status
	_update_connection_display()

	# Periodic refresh
	var timer = Timer.new()
	timer.wait_time = 5.0
	timer.autostart = true
	timer.timeout.connect(_update_connection_display)
	add_child(timer)

func _update_connection_display():
	if NakamaManager.is_connected:
		connection_dot.color = Color(0.2, 0.8, 0.3)  # Green
		connection_label.text = "Connected"
	else:
		connection_dot.color = Color(1.0, 0.5, 0.0)  # Orange
		connection_label.text = "Disconnected"

func _on_connection_lost():
	_update_connection_display()

func _on_connection_restored():
	_update_connection_display()
```

### 6.2 Quit Interception When Disconnected

**In NakamaManager (nakama_client.gd)**:

```gdscript
# Tracks last successful cloud save timestamp (in memory)
var last_successful_save_timestamp: float = 0.0

func _notification(what):
	if what == NOTIFICATION_WM_CLOSE_REQUEST:
		_handle_quit_request()

func _handle_quit_request():
	if is_connected:
		# Connected - safe to quit
		get_tree().quit()
	else:
		# Disconnected - show warning popup
		_show_unsaved_progress_warning()

func _show_unsaved_progress_warning():
	# Format timestamp for display
	var last_save_str = _format_timestamp(last_successful_save_timestamp)

	# Create popup (uses popup system from popup-system.md)
	var popup = preload("res://ui/unsaved_warning_popup.tscn").instantiate()
	popup.set_last_save_time(last_save_str)
	popup.reconnect_pressed.connect(_on_reconnect_pressed)
	popup.close_anyway_pressed.connect(_on_close_anyway_pressed)

	# Add to PopupContainer
	var popup_container = get_tree().current_scene.get_node_or_null("PopupContainer")
	if popup_container:
		popup_container.add_child(popup)
	else:
		# Fallback if no PopupContainer
		get_tree().current_scene.add_child(popup)

func _format_timestamp(unix_time: float) -> String:
	if unix_time == 0.0:
		return "Never"
	var datetime = Time.get_datetime_dict_from_unix_time(int(unix_time))
	return "%02d:%02d %s" % [
		datetime.hour % 12 if datetime.hour % 12 != 0 else 12,
		datetime.minute,
		"AM" if datetime.hour < 12 else "PM"
	]

func _on_reconnect_pressed():
	# Attempt to save
	var success = await save_game()
	if success:
		get_tree().quit()
	# If failed, popup stays open (user can try again or close anyway)

func _on_close_anyway_pressed():
	# Force quit without saving
	get_tree().quit()
```

```
        +-- ButtonHBox (HBoxContainer)

```

**unsaved_warning_popup.gd**:
```gdscript
extends PanelContainer

signal reconnect_pressed
signal close_anyway_pressed

@onready var message_label = $MarginContainer/VBoxContainer/MessageLabel
@onready var reconnect_button = $MarginContainer/VBoxContainer/ButtonHBox/ReconnectButton
@onready var close_anyway_button = $MarginContainer/VBoxContainer/ButtonHBox/CloseAnywayButton

func _ready():
	reconnect_button.pressed.connect(func(): reconnect_pressed.emit())
	close_anyway_button.pressed.connect(func(): close_anyway_pressed.emit())

func set_last_save_time(time_str: String):
	message_label.text = "Last save: %s\nProgress since then will be lost." % time_str
```

## Offline Earnings Calculation

When player logs in after being offline, offline earnings use `last_successful_save_timestamp` from the cloud save - NOT the current time minus some arbitrary "last played" value.

**Flow**:
1. Player closes game while connected -> save succeeds -> `timestamp` in cloud = close time
2. Player closes game while disconnected -> warned -> cloud save unchanged
3. Player returns -> load cloud save -> offline earnings = `now - save.timestamp`

**No Exploit Possible**:
- Staying offline longer doesn't help (earnings calculated from last SUCCESSFUL save)
- Disconnecting intentionally doesn't help (same reason)
- Only way to "game" it is to stay connected, which is the intended behavior
