# Nakama Authentication Methods

## Overview
Implement all three authentication methods for Nakama: Device ID, Username/Password, and Google OAuth.

**Parent Plan**: [../1.17-nakama-server.md](../1.17-nakama-server.md) (index)
**Depends On**: [1.17.1-core-client.md](1.17.1-core-client.md)

## Purpose
- Device ID auth for low-friction cloud saves
- Username/Password for portable accounts
- Google OAuth for web builds
- Session persistence across app restarts
- Connection recovery with retry logic

All three authentication methods create cloud-based Nakama accounts. There are NO local saves or offline fallback.

## Implementation

### 2.1 Device ID Authentication
Cloud-based authentication using device ID - no username/password required.

**Purpose**: Low-friction authentication that still provides cloud saves.

```gdscript
func authenticate_device() -> bool:
	var device_id = _get_device_id()
	var result = await _authenticate_with_retry(func():
		return await client.authenticate_device_async(device_id, null, true, {})
	)
	return result

func _get_device_id() -> String:
	var id = OS.get_unique_id()
	if id.is_empty():
		# Web builds may return empty - use persistent fallback
		id = _load_or_create_web_device_id()
	return id

func _load_or_create_web_device_id() -> String:
	const WEB_ID_PATH = "user://web_device_id.dat"
	if FileAccess.file_exists(WEB_ID_PATH):
		var file = FileAccess.open(WEB_ID_PATH, FileAccess.READ)
		if file:
			return file.get_as_text()

	# Generate new UUID
	var uuid = _generate_uuid()
	var file = FileAccess.open(WEB_ID_PATH, FileAccess.WRITE)
	if file:
		file.store_string(uuid)
	return uuid

func _generate_uuid() -> String:
	# Simple UUID v4 generation
	var chars = "0123456789abcdef"
	var uuid = ""
	for i in range(32):
		if i == 8 or i == 12 or i == 16 or i == 20:
			uuid += "-"
		uuid += chars[randi() % 16]
	return uuid
```

**Note**: Device ID creates a CLOUD account linked to this device. It's not "offline mode" - it's cloud-based authentication without username/password.

### 2.2 Username/Password Authentication
For players who want portable accounts accessible from any device.

**Purpose**: Manual account creation and login with secure server-side password hashing.

```gdscript
func authenticate_username_password(username_input: String, password: String, create_account: bool) -> bool:
	# Use authenticate_custom_async for arbitrary usernames (not email format)
	var result = await _authenticate_with_retry(func():
		return await client.authenticate_custom_async(username_input, create_account, username_input, {
			"password": password
		})
	)
	return result
```

**Security Note**: Uses Nakama's `authenticate_custom_async()` with server-side password validation. The password is passed in vars and validated by a server-side hook. This allows arbitrary usernames (not email format).

**Server Hook Required**: Register a `before_authenticate_custom` hook on Nakama server to validate password:
```lua
-- In main.lua on Nakama server
local function before_authenticate_custom(context, payload)
    local password = payload.vars["password"]
    if not password or #password < 6 then
        error("Password must be at least 6 characters")
    end
    -- Hash and store password server-side
    -- (Implementation depends on your server setup)
    return payload
end
nk.register_before(before_authenticate_custom, "AuthenticateCustom")
```

### 2.4 Common Authentication Handler
All auth methods use this to reduce duplication and handle errors consistently.

```gdscript
func _authenticate_with_retry(auth_callable: Callable) -> bool:
	var auth_result = await auth_callable.call()

	if auth_result.is_exception():
		var error = auth_result.get_exception().message
		authentication_failed.emit(error)
		return false

	session = auth_result as NakamaSession
	_set_auth_state(session)
	authentication_succeeded.emit(_get_session_data())
	return true
```

### 2.5 Helper Functions
```gdscript
func _set_auth_state(nakama_session: NakamaSession):
	is_authenticated = true
	user_id = nakama_session.user_id
	username = nakama_session.username
	session = nakama_session
	_save_session_data(nakama_session)

func _clear_auth_state():
	is_authenticated = false
	user_id = ""
	username = ""
	session = null

func _get_session_data() -> Dictionary:
	return {
		"user_id": user_id,
		"username": username,
		"session": session
	}

func logout():
	_clear_auth_state()
	_clear_session_data()
	DebugLogger.info("User logged out", "NAKAMA")
```

### 2.6 Session Persistence
Store session tokens to avoid re-authentication on every launch.

**Save Session Data** (token + refresh token + username):
```gdscript
const SESSION_DATA_PATH = "user://nakama_session.json"

func _save_session_data(nakama_session: NakamaSession):
	var data = {
		"token": nakama_session.token,
		"refresh_token": nakama_session.refresh_token,
		"username": nakama_session.username,
		"user_id": nakama_session.user_id
	}
	var file = FileAccess.open(SESSION_DATA_PATH, FileAccess.WRITE)
	if file:
		file.store_string(JSON.stringify(data))
		DebugLogger.info("Session data saved", "NAKAMA")
	else:
		DebugLogger.error("Failed to save session data", "NAKAMA")
```

**Load Session Data**:
```gdscript
func _load_session_data() -> Dictionary:
	if not FileAccess.file_exists(SESSION_DATA_PATH):
		return {}

	var file = FileAccess.open(SESSION_DATA_PATH, FileAccess.READ)
	if not file:
		return {}

	var json_string = file.get_as_text()
	var data = JSON.parse_string(json_string)
	if data == null:
		return {}

	return data
```

**Restore Session**:
```gdscript
func _restore_session() -> bool:
	var data = _load_session_data()
	if data.is_empty():
		return false

	var token = data.get("token", "")
	var refresh_token = data.get("refresh_token", "")

	if token.is_empty():
		return false

	# Reconstruct session from stored tokens
	session = NakamaSession.new(token, refresh_token)

	# Check if session is expired locally first
	if session.is_expired():
		DebugLogger.info("Stored session expired", "NAKAMA")
		_clear_session_data()
		return false

	# Validate session with server (may be invalidated server-side)
	var account = await client.get_account_async(session)
	if account.is_exception():
		DebugLogger.info("Session invalid on server", "NAKAMA")
		_clear_session_data()
		return false

	# Session valid - restore auth state
	is_authenticated = true
	user_id = data.get("user_id", session.user_id)
	username = data.get("username", account.user.username)

	DebugLogger.info("Session restored for user: " + username, "NAKAMA")
	authentication_succeeded.emit(_get_session_data())
	return true

func _clear_session_data():
	if FileAccess.file_exists(SESSION_DATA_PATH):
		DirAccess.remove_absolute(SESSION_DATA_PATH)
```

### 2.7 Startup Connection Recovery
Handle connection failures during startup with retry modal.

**Why**: No local saves means no offline mode. If we can't connect, the game can't be played.

```gdscript
signal connection_recovery_requested()  # UI shows retry modal
signal connection_recovery_cancelled()  # User chose to quit

const MAX_RETRY_ATTEMPTS = 3
const RETRY_DELAYS = [1.0, 2.0, 4.0]  # Exponential backoff in seconds

func attempt_startup_connection() -> bool:
	# Try to restore existing session first
	var data = _load_session_data()
	if not data.is_empty():
		var restored = await _restore_session_with_retry()
		if restored:
			return true

	# No session to restore - need fresh authentication
	# Return false to indicate UI should show login options
	return false

func _restore_session_with_retry() -> bool:
	for attempt in range(MAX_RETRY_ATTEMPTS):
		var success = await _restore_session()
		if success:
			return true

		# Check if it's a network error vs invalid session
		if not _is_network_error():
			# Session is invalid, not a network issue - don't retry
			return false

		if attempt < MAX_RETRY_ATTEMPTS - 1:
			DebugLogger.info("Retry attempt " + str(attempt + 1) + " failed, waiting...", "NAKAMA")
			await get_tree().create_timer(RETRY_DELAYS[attempt]).timeout

	# All retries exhausted - emit signal for UI to show modal
	connection_recovery_requested.emit()
	return false

var _last_error_was_network: bool = false

func _is_network_error() -> bool:
	return _last_error_was_network

func show_connection_retry_modal():
	# Called by UI when connection_recovery_requested is emitted
	# Modal shows: "Cannot connect to cloud. [Retry] [Quit]"
	pass  # UI implementation handles this

func retry_connection() -> bool:
	# Called when user clicks Retry in modal
	var success = await _restore_session_with_retry()
	if not success:
		# Still failing - keep modal open
		connection_recovery_requested.emit()
	return success

func cancel_connection_recovery():
	# Called when user clicks Quit in modal
	connection_recovery_cancelled.emit()
	get_tree().quit()
```

**Flow**:
1. Game starts -> `attempt_startup_connection()`
2. If stored session exists, try to restore with retries
3. If all retries fail, emit `connection_recovery_requested`
4. UI shows modal: "Cannot connect to cloud. [Retry] [Quit]"
5. User clicks Retry -> `retry_connection()` -> retry loop
6. User clicks Quit -> `cancel_connection_recovery()` -> exit game
