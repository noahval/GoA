# Google OAuth (Web Builds)

## Overview
Add Google Sign-In for web builds using JavaScript interop.

**Depends On**: [1.17.2-authentication.md](1.17.2-authentication.md)
**Reference Docs**: [.claude/docs/nakama-integration.md](.claude/docs/nakama-integration.md#L138-L159)

## Purpose
- Allow web players to sign in with Google accounts
- One-click authentication (no username/password to remember)
- Uses existing Google OAuth config on Nakama server

---

## Implementation

### 7.1 HTML Template Setup

Add Google Sign-In script to the HTML5 export template.

**File**: `game/v0.1/export/web/index.html` (or custom template)

```html
<!-- In <head> -->
<script src="https://accounts.google.com/gsi/client" async defer></script>

<script>
var googleIdToken = null;

function initGoogleSignIn() {
    google.accounts.id.initialize({
        client_id: 'YOUR_GOOGLE_CLIENT_ID.apps.googleusercontent.com',
        callback: handleGoogleResponse
    });
}

function handleGoogleResponse(response) {
    googleIdToken = response.credential;
    // Notify Godot that token is ready
    if (window.godotGoogleCallback) {
        window.godotGoogleCallback(googleIdToken);
    }
}

function triggerGoogleSignIn() {
    google.accounts.id.prompt();
}

function getGoogleToken() {
    return googleIdToken;
}
</script>
```

### 7.2 GDScript JavaScript Interop

**Add to** `nakama_manager.gd`:

```gdscript
signal google_token_received(token: String)

func authenticate_google_web() -> bool:
    if not OS.has_feature("web"):
        DebugLogger.error("Google auth only available on web", "NAKAMA")
        authentication_failed.emit("Google sign-in not available")
        return false

    # Set up callback for when JS returns the token
    JavaScriptBridge.create_callback(_on_google_token_received)
    JavaScriptBridge.eval("window.godotGoogleCallback = Module.cwrap('_on_google_token_received', null, ['string']);")

    # Trigger Google Sign-In popup
    JavaScriptBridge.eval("triggerGoogleSignIn();")

    # Wait for token (with timeout)
    var token = await _wait_for_google_token(30.0)
    if token.is_empty():
        authentication_failed.emit("Google sign-in timed out")
        return false

    return await _authenticate_with_google_token(token)

func _wait_for_google_token(timeout: float) -> String:
    var elapsed = 0.0
    while elapsed < timeout:
        if _pending_google_token != "":
            var token = _pending_google_token
            _pending_google_token = ""
            return token
        await get_tree().create_timer(0.1).timeout
        elapsed += 0.1
    return ""

var _pending_google_token: String = ""

func _on_google_token_received(token: String):
    _pending_google_token = token

func _authenticate_with_google_token(token: String) -> bool:
    var result = await client.authenticate_google_async(token, null, true, {})

    if result.is_exception():
        var error = result.get_exception().message
        DebugLogger.error("Google auth failed: " + error, "NAKAMA")
        authentication_failed.emit("Google authentication failed")
        return false

    session = result as NakamaSession
    is_authenticated = true
    user_id = session.user_id
    username = session.username
    _save_session_data(session)
    DebugLogger.info("Google auth successful: " + username, "NAKAMA")
    authentication_succeeded.emit({"user_id": user_id, "username": username})
    return true
```

### 7.3 Login UI Integration

Add Google button to login screen (web builds only).

```gdscript
# In login_screen.gd or similar
func _ready():
    if OS.has_feature("web"):
        $GoogleSignInButton.visible = true
        $GoogleSignInButton.pressed.connect(_on_google_pressed)
    else:
        $GoogleSignInButton.visible = false

func _on_google_pressed():
    $GoogleSignInButton.disabled = true
    var success = await NakamaManager.authenticate_google_web()
    $GoogleSignInButton.disabled = false
    if success:
        _go_to_game()
```

## Server Configuration

Google OAuth is already configured on Nakama server:
- **Config location**: `z:\appdata\nakama\data\config.yml`
- **Client ID**: Set in `social.google.client_id`

No server changes needed - just use the existing client ID in the HTML template.

## Notes & Decisions

**Decision 1**: Use Google Identity Services (new library)
- **Rationale**: Google deprecated the old `gapi.auth2` library
- **Library**: `accounts.google.com/gsi/client`

**Decision 2**: 30 second timeout for token
- **Rationale**: User may cancel popup or take time to choose account
- **Fallback**: Show "timed out" error, user can retry

**Decision 3**: Web-only feature
- **Rationale**: Desktop/mobile would need platform-specific Google SDKs
- **Implementation**: Check `OS.has_feature("web")` before showing button
